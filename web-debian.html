Serveurs web Debian et réplication MySQL.

Publier deux sites virtuels et contrôler la réplication entre deux serveurs.

Debian · Apache · BIND9 · MySQL

Services web et DNS

Sur deux VM Debian, j’ai configuré la zone DNS du TP et les hôtes virtuels Apache pour les sites SISR et SLAM. J’ai vérifié les réponses DNS avec dig.

Dépannage

Lors du démarrage de la réplication MySQL, une erreur 1045 signalait un refus d’accès. Après correction des droits du compte de réplication, le démarrage a abouti.

Vérification

Une table de test et des insertions ont servi à vérifier la circulation des données entre les instances. Les pièces jointes décrivent les consignes techniques du TP.
